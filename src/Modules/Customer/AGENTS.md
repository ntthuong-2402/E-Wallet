# Customer Module Instructions

Apply these rules with the repository-root `AGENTS.md`.

## Scope and ownership

- Customer owns customer profiles, lifecycle state, CustomerCode, and Customer
  change audit records.
- Admin/Identity owns credentials, sessions, roles, and permissions.
- Store cross-context identities as external references only. Do not query Admin
  tables or create cross-context foreign keys.

## Boundaries

- Preserve project direction: Domain <- Application <- Infrastructure.
- Customer owns `CustomerDbContext`, the `customer` schema, migrations, and its
  transaction boundary.
- Customer commands implement `ICustomerCommand<TResponse>` so the shared CQRS
  pipeline selects `CustomerUnitOfWork` explicitly.
- API endpoints remain thin adapters in `Friday.API`.

## Security

- Customer PII must not enter logs or unprotected audit payloads.
- CustomerCode is generated by the system and is immutable.
- Closed is a terminal lifecycle state.
